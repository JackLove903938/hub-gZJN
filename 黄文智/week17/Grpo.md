# GRPO 算术题模型对比报告

## 1. 实验概览

| 项目 | 说明 |
|------|------|
| 基座模型 | Qwen2-0.5B-Instruct |
| 训练方法 | GRPO（Group Relative Policy Optimization，无价值网络、无奖励模型） |
| 训练步数 | 200 步（每步 4 prompt × 8 采样 = 32 条 completion） |
| 奖励函数 | 正确分（1.0）+ 格式分（0.2），复合奖励塑形 |
| 训练集难度 | L2_addsub_2digit (25%)、L3_addsub_3digit (50%)、L5_mul_2x1digit (25%) |
| 泛化评估难度 | L1_add_1digit、L4_mul_1digit、L6_mul_2x2digit（未进训练集） |
| 评估配置 | 每难度 50 题，K=8 采样，seed=42（训练前后同一评估集） |

### 三个对比模型

| 标签 | 数据来源 | 说明 |
|------|----------|------|
| **基座模型** | `baseline_probe.json` | Qwen2-0.5B-Instruct 原始权重，未经任何训练 |
| **全量GRPO** | `post_train_probe.json` | 全参数 GRPO 微调，lr=2e-6，训练耗时 196.5s |
| **LoRA GRPO** | `post_train_probe_lora.json` | LoRA GRPO 微调（r=16, alpha=32, target=q/k/v/o_proj），lr=2e-4，训练耗时 668.0s |

## 2. 核心指标说明

| 指标 | 含义 |
|------|------|
| `greedy_format_rate` | 贪心解码输出中包含 `<answer>数字</answer>` 格式的比例 |
| `greedy_strict_acc` | 贪心解码严格准确率：格式正确 **且** 答案正确 |
| `greedy_loose_acc` | 贪心解码宽松准确率：输出中包含正确数字即可（不要求格式） |
| `sample_strict_acc` | K=8 采样的平均严格准确率 |
| `sample_loose_acc` | K=8 采样的平均宽松准确率 |
| `pass@8` (strict) | 8 次采样中至少 1 次严格正确的比例 |
| `loose_pass@8` | 8 次采样中至少 1 次宽松正确的比例 |
| `informative_group_rate` | 组内奖励非全相同的比例（GRPO 有效梯度信号占比） |

## 3. 贪心解码准确率对比（核心表）

> 以下为各难度级别贪心解码的**格式率 / 严格准确率 / 宽松准确率**对比。

| 难度 | 训练集 | 基座模型 (格式/严格/宽松) | 全量GRPO (格式/严格/宽松) | LoRA GRPO (格式/严格/宽松) |
|------|:------:|:---:|:---:|:---:|
| L1_add_1digit | — | 0.00 / 0.00 / 0.98 | 0.96 / 0.96 / 1.00 | **1.00 / 1.00 / 1.00** |
| L2_addsub_2digit | √ | 0.02 / 0.02 / 0.76 | 1.00 / 0.98 / 0.98 | **1.00 / 0.98 / 0.98** |
| L3_addsub_3digit | √ | 0.02 / 0.02 / 0.40 | 0.96 / 0.86 / 0.90 | **1.00 / 0.92 / 0.92** |
| L4_mul_1digit | — | 0.00 / 0.00 / 0.56 | 0.82 / 0.82 / 1.00 | **1.00 / 1.00 / 1.00** |
| L5_mul_2x1digit | √ | 0.00 / 0.00 / 0.20 | 0.98 / 0.86 / 0.88 | **1.00 / 0.94 / 0.94** |
| L6_mul_2x2digit | — | 0.04 / 0.00 / 0.08 | 0.98 / 0.24 / 0.24 | **1.00 / 0.28 / 0.28** |

### 关键发现

1. **格式规范**：基座模型几乎不输出 `<answer>` 标签（格式率 ≈ 0），两个训练后模型格式率均接近 1.0，LoRA GRPO 达到完美的 1.00。
2. **严格准确率大幅提升**：基座模型严格准确率几乎为 0（不会按格式输出），训练后全量GRPO 和 LoRA GRPO 在各难度均有显著提升。
3. **LoRA GRPO 整体优于全量GRPO**：在所有 6 个难度上，LoRA GRPO 的严格准确率均 ≥ 全量GRPO，尤其在 L1（+4%）和 L4（+18%）泛化难度上优势明显。
4. **L6_mul_2x2digit 仍是瓶颈**：两位数乘法对 0.5B 模型过于困难，即使训练后严格准确率也仅 24%~28%。

## 5. 泛化能力分析

训练集仅包含 L2、L3、L5 三个难度，L1、L4、L6 用于评估泛化能力。

| 评估类型 | 难度 | 基座模型严格 acc | 全量GRPO 严格 acc | LoRA GRPO 严格 acc | 提升（LoRA vs 基座） |
|----------|------|:---:|:---:|:---:|:---:|
| 训练集内 | L2 | 0.02 | 0.98 | 0.98 | +0.96 |
| 训练集内 | L3 | 0.02 | 0.86 | 0.92 | +0.90 |
| 训练集内 | L5 | 0.00 | 0.86 | 0.94 | +0.94 |
| **泛化** | L1 | 0.00 | 0.96 | **1.00** | +1.00 |
| **泛化** | L4 | 0.00 | 0.82 | **1.00** | +1.00 |
| **泛化** | L6 | 0.00 | 0.24 | **0.28** | +0.28 |

- **简单泛化（L1/L4）**：两个模型均表现优异，LoRA GRPO 达到 100%，说明模型学会了算术运算的通用能力，而非仅记住训练题。
- **困难泛化（L6）**：两位数乘法提升有限（基座 0% → LoRA 28%），说明 0.5B 模型参数量不足以支撑复杂多位乘法的可靠计算。

## 6. 训练动态对比

### 6.1 训练配置差异

| 配置项 | 全量GRPO | LoRA GRPO |
|--------|----------|-----------|
| 学习率 | 2e-6 | 2e-4 |
| 可训练参数 | 全部 | LoRA adapters（r=16, alpha=32） |
| 目标模块 | 全部 | q_proj, k_proj, v_proj, o_proj |
| 训练耗时 | 196.5s | 668.0s |
| 吞吐量 | 32.6 samples/s | 9.6 samples/s |

### 6.2 训练终态指标（第 200 步）

| 指标 | 全量GRPO | LoRA GRPO |
|------|----------|-----------|
| 正确奖励均值 | 0.844 | **0.950** |
| 格式奖励均值 | 0.176 | **0.200** |
| 总奖励均值 | 1.020 | **1.150** |
| 奖励标准差 | 0.238 | **0.085** |
| 退化组比例 (frac_reward_zero_std) | 0.30 | 0.80 |
| 策略熵 (entropy) | 0.102 | **0.018** |
| 平均 completion 长度 | 9.5 | 10.2 |

### 6.3 训练动态解读

- **LoRA GRPO 奖励更高且更稳定**：终态正确奖励 0.95 vs 0.84，奖励标准差 0.085 vs 0.238，说明 LoRA 模型输出更一致。
- **LoRA GRPO 熵更低（0.018 vs 0.102）**：策略更趋确定，模型对正确答案更有信心，但退化组比例高达 0.80（80% 的组内 8 条采样奖励完全相同），意味着探索性下降。
- **全量GRPO 探索性更好**：较低的退化组比例（0.30）和较高的熵（0.102）说明策略仍保持多样性，但在 0.5B 模型上学习效率不如 LoRA。
- **格式分先收敛、正确分后爬坡**：两个实验均呈现这一典型 RL 训练动态——模型先学会输出格式，再逐步提升计算正确率。

## 8. 总结

| 维度 | 基座模型 | 全量GRPO | LoRA GRPO |
|------|----------|----------|-----------|
| 格式规范 | 几乎无（≈0%） | 优秀（82%~100%） | **完美（100%）** |
| 简单加减法 (L1-L2) | 宽松可用，无格式 | 优秀 | **完美** |
| 中等运算 (L3-L5) | 较差 | 良好 | **优秀** |
| 困难乘法 (L6) | 极差 | 有限提升 | 略优 |
| 泛化能力 | — | 强 | **更强** |
| 训练效率 | — | **更快**（196s） | 较慢（668s） |
| 策略稳定性 | — | 探索性好 | **更收敛** |

**结论**：在 Qwen2-0.5B-Instruct 上进行 GRPO 算术训练，LoRA 微调（r=16, lr=2e-4）在准确率、格式规范和泛化能力上均优于全量微调（lr=2e-6），但训练耗时约为 3.4 倍。两者的共同瓶颈在于两位数乘法（L6），这受限于 0.5B 模型的参数容量。
