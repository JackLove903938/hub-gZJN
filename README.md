实验skill的压缩进化
下面对课上的Inquiry-dtc技能进行了压缩，token大幅下降的同时，效果基本不变，节省了未来使用的成本



SKILL.md（3602B → 1641B，约 1135 → 509 tokens，↓55.2%）
- 触发场景从 5 条示例压缩为 1 行（frontmatter description 里已含触发语义，冗余）
- 合并"输出说明"与"注意事项"为"注意"，删除与流程重复的描述
- 知识库字段清单压缩为一行内联
- 保留 frontmatter（name/description）原样，保证 skill 可被正常识别与触发

make_dtc_report.py（10738B → 8587B，约 2978 → 2367 tokens，↓20.5%）
- 去掉 argparse，改用 sys.argv 手写循环解析（-o/--no-open 行为不变）
- 函数合并：kb/find/norm/family/card/page，用 next()/推导式减少样板代码
- CSS 压缩为每条规则一行并内联颜色变量（视觉样式不变，渲染效果一致）
- 删除冗长 docstring（15 行 → 4 行），仅保留用法说明
